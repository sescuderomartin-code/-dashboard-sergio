Guía de buenas prácticas

  • Exporta un JSON después de cada actualización importante de tus inversiones.
  • Guarda el JSON en una carpeta segura, nube privada o disco externo.
  • El ZIP guarda la app; el JSON guarda tus datos. Son cosas distintas: la app es el coche, el JSON es la gasolina.
  • Antes de importar, exporta una copia del estado actual por seguridad.
  • No compartas tu backup si contiene importes reales o información sensible.
